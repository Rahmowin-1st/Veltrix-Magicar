# Veltrix Ultron V0 Integration Scope

This integration layer combines the first executable foundations:

- Android Compose application shell
- Mission lifecycle with pause/resume/cancel/take-over
- Proof-of-done invariant: DONE requires evidence
- Scoped permission/delegation contracts
- Accessibility executor foundation
- Personal memory and private-memory controls
- Conversation and follow-up context
- Free-only capability-aware Brain Router with provider health/fallback
- Agent Gateway contracts
- Offline/cloud-aware mission queue
- Windows self-hosted Android CI bootstrap

This is foundation code, not a claim that full device autonomy is complete. Runtime capabilities remain gated by Android permissions, device configuration, and later verification layers.
